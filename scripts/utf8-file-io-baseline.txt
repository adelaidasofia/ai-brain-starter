# THIS FILE IS A BACKLOG, NOT A SET OF PARDONS.
#
# Every row is a tracked file doing text-mode file I/O with no explicit
# encoding=, so it uses locale.getpreferredencoding() - cp1252 on a stock
# Windows box, UTF-8 on macOS/Linux. The same source therefore produces
# differently-encoded artifacts depending on whose machine ran it, and all three
# measured failure modes are SILENT (see the lint header): a write that corrupts
# without raising, a read that decodes into mojibake without raising, and a read
# that raises on the five bytes undefined in cp1252 and gets swallowed by a bare
# `except`. PYTHONUTF8=1 hides the entire class from whoever is maintaining it.
#
# Rows here predate the guard. Pinning them lets the CLASS-level gate land
# without a 71-file rewrite, while still failing the build for anything new:
#   - a file NOT listed here has NO grace period;
#   - EDITING a listed file changes its hash and fails until it is fixed.
# Fix a row by passing encoding="utf-8" and DELETING its line - the lint reports
# leftover rows as stale.
#
